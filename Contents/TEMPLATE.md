# 학습 노트 작성 템플릿

## 공통 양식

아래 양식을 복사해 사용합니다. 기록일은 실제 날짜를 아는 경우에만 작성하고, 출처에는 책 제목·영상 링크·직접 작성한 기록임을 표시합니다.

````markdown
# 문서 제목

- 분류: 독서 / 실습 / 질문 / 영상 중 하나
- 기록일: YYYY-MM-DD
- 출처: 책 제목 / [영상 제목](URL) / 개인 학습 질문 / 직접 구현 및 실험 기록

## 목차

- [첫 번째 주제](#첫-번째-주제)
- [두 번째 주제](#두-번째-주제)

## 첫 번째 주제

설명과 학습 내용을 작성합니다.

### 세부 주제

- 필요한 항목을 정리합니다.

```text
코드나 실행 결과를 기록합니다.
```

## 두 번째 주제

설명과 학습 내용을 작성합니다.
````

## 작성 규칙

- 문서 제목은 H1(`#`) 하나만 사용하고, 본문은 H2(`##`)부터 순서대로 작성합니다.
- 목차에는 본문의 H2 제목을 연결합니다.
- 질문 노트는 `## 질문 1`, `## 답변 1`을 한 쌍으로 작성하고, 추가 질문은 번호를 늘립니다.
- 실습 노트는 배경·계획·구현·결과·시행착오 등 실제 기록이 있는 항목만 작성합니다.
- 출처를 알 수 없는 정보나 작성하지 않은 결론을 채워 넣지 않습니다.
- 코드는 언어를 지정한 코드 블록에 넣고, 비교 표는 한 행을 한 줄로 작성합니다.
- 저장소 이미지는 현재 파일 기준 상대 경로를 사용합니다. 원본 첨부가 없으면 파일이 없다는 사실을 텍스트로 남깁니다.

## 긴 독서 노트 분리 규칙

- 독립된 주제가 여러 개이고 수백 줄에 이르면 기존 챕터 경계로 나눕니다.
- 원래 파일은 책 제목·출처·챕터 목차를 담은 진입점으로 유지합니다.
- 같은 이름의 폴더 아래에 `01.챕터 제목.md`, `02.챕터 제목.md` 순서로 저장합니다.
- 이미 챕터 폴더로 나뉜 책은 기존 구조를 유지하고 책 폴더에 `README.md` 목차를 둡니다.
- 챕터에는 책 목차로 돌아가는 링크를 추가합니다.
