## 실습 배경

Wokwi로 Arduino·ESP32 실습을 시작했다. 코드를 따라 쓰기 전에 회로의 기본 구성과 핀의 역할부터 이해할 필요가 있었다.

## 기본 개념

| 개념 | 역할 |
| --- | --- |
| 전압 V | 두 지점 사이의 전위차 |
| 전류 A | 전하가 흐르는 양 |
| 저항 Ω | 전류의 흐름을 제한하는 정도, Ω은 단위 |
| GND | 전압을 비교하는 기준, 보통 0V로 사용 |
| VCC | 전원 단자 표기, 언제나 5V라는 뜻은 아님 |
| GPIO | 디지털 신호를 읽거나 출력하는 핀, 핀마다 지원 기능 확인 필요 |

옴의 법칙은 I = V / R이다. LED 직렬 저항은 보드 전압과 LED의 순방향 전압·허용 전류를 고려한다. 여러 LED는 각 가지의 전류 제한도 확인한다.

## 배선과 코드의 연결

~~~text
출력 핀 → 저항 → LED 애노드 A → LED 캐소드 C → GND
출력 HIGH: 전류가 흐르며 켜지는 active-high 구성

전원 → 저항 → LED → 출력 핀
출력 LOW: 핀이 전류를 받아 켜지는 active-low 구성
~~~

GPIO는 전원 핀과 역할이 다르다. ESP32의 논리 전압과 입력 허용 전압을 확인하고, 5V 전원을 GPIO에 그대로 연결해도 된다고 가정하지 않는다.

## 시행착오

- define 매크로 값 뒤의 세미콜론이 치환되면서 pinMode 등의 인자 문법이 깨지는 문제
- 일반 ESP32의 GPIO34·35를 출력으로 사용하려 한 문제
- 처음 선택한 ESP32-S2와 이후 실제 프로젝트의 ESP32-DevKitC V4가 달랐던 문제

~~~cpp
#define LED_PIN 33

void setup() {
  pinMode(LED_PIN, OUTPUT);
}
~~~

일반 ESP32의 GPIO34~39는 입력 전용이다. 이 제약을 ESP32-S2·S3 등 모든 보드에 동일하게 적용하지 않는다. [Espressif GPIO 문서](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/peripherals/gpio.html)

## 결과와 다음 확인

- 사용자가 버튼에 따라 LED를 켜고 끄는 동작을 구현했다고 보고
- 이후 누르는 동안 반복 토글되는 문제를 발견해 눌림 순간 감지와 디바운싱으로 진행
- 회로를 볼 때 실제 보드 → 핀 기능 → 부품 값 → GND → 코드 정의 순서로 대조
