## 프로젝트 설정

### 프론트엔드 패턴

- 설명 기반 구성 요소 구현
- 스타일링과 레이아웃
- API 및 상태 관리
- 복잡성 분해
- 프레임워크별 주의점

### 백엔드/API 패턴

- 엔드포인트 구현
- DB 통합
- 비즈니스 로직 검증
- 오케스트레이션
- 문서화 및 테스트

## 데이터베이스 설계

도메인 이해가 가장 중요하다.

- ORM 모델 생성
- SQL 쿼리 작성
- 쿼리 검증 및 무결성 확인

## 풀스택 통합

- API 규약 맞추기
- 상태 관리 및 실시간 통합

**전략**

- AI는 구조, 개발자는 커스텀 로직
- 단계별 처리
- 품질 개선 및 교차 검증

## 테스트와 검증

- 유닛 / 통합 / 프론트엔드 테스트
- 수동 테스트
- 코드 리뷰
- 보안 점검

이를 통해 엣지 케이스를 보완하고 코드를 강화한다.
