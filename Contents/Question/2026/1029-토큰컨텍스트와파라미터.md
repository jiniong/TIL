## 질문 1

모델 설명의 최대 토큰, 파라미터 수, 활성 파라미터 수는 같은 규모를 뜻할까?

## 답변 1

| 지표 | 의미 |
| --- | --- |
| 파라미터 수 | 모델의 학습된 수치 개수 |
| 활성 파라미터 수 | MoE 등에서 특정 토큰 계산에 참여하는 규모 |
| 컨텍스트 길이 | 한 요청에서 참고할 수 있는 토큰의 전체 범위 |
| 최대 출력 토큰 | 한 응답에서 생성할 수 있는 토큰의 상한 |
| 초당 출력 토큰 | 생성 속도, 답변 정확도와는 별개의 지표 |

컨텍스트가 32K이고 최대 출력이 8K라는 가상 조건에서 입력이 30K라면, 합계 제한을 적용하는 시스템에서는 출력 여유가 약 2K다. 모델·서비스의 실제 제한과 내부 추론 토큰 집계는 별도 확인한다.

토큰은 토크나이저가 정한 텍스트 조각이다. 단어·글자·의미의 최소 단위와 일치하지 않고, 같은 문장도 토크나이저에 따라 개수가 달라진다.

## 질문 2

파라미터 하나는 실제로 무엇이고 직접 바꾸면 어떤 답이 나올까?

## 답변 2

행렬 원소 등 모델 계산에 쓰이는 학습된 숫자다. 하나의 숫자에 “서울”, “존댓말”, “수학 능력” 같은 의미가 각각 배정된 구조로 생각하면 안 된다.

값을 바꾸면 중간 계산과 다음 토큰의 확률이 달라질 수 있지만, 실제 출력이 그대로일 수도 있다. 원하는 행동은 보통 예시 데이터와 학습으로 많은 관련 숫자를 함께 조정한다.

## 질문 3

가중치가 공개된 3조 파라미터 모델을 개인 PC에서 수정할 수 있을까?

## 답변 3

아래는 실제 특정 모델의 사양이 아니라 단순한 용량 계산이다. 사용 권한은 해당 라이선스도 확인해야 한다.

| 저장 정밀도 | 3조 개의 원시 가중치 크기, 십진 단위 |
| --- | ---: |
| 16비트, 2바이트 | 약 6TB |
| 4비트, 0.5바이트 | 약 1.5TB |

스케일 등 양자화 메타데이터, KV cache, 활성값, 런타임 메모리는 포함하지 않은 계산이다. 학습에는 기울기·옵티마이저 상태 등도 필요하다. MoE에서 일부만 활성화된다고 전체 가중치 저장 부담이 활성 규모로 줄어드는 것은 아니다.

원문에 붙여 넣은 모델명·파라미터·컨텍스트 수치를 모두 검증한 것은 아니므로 특정 모델의 확정 사양표로 재사용하지 않는다.
