## 질문 1

서버를 빌리는 것과 컨테이너를 띄우는 것은 무엇이 다를까?

## 답변 1

서버는 실행 자원을 제공하고, 컨테이너는 그 자원 위에서 프로세스를 격리해 실행하는 방식이다.

| 구분 | VM | 일반적인 Linux 컨테이너 |
| --- | --- | --- |
| 실행 환경 | 가상 하드웨어 위에서 별도의 게스트 OS 실행 | 호스트 커널을 공유하며 프로세스·파일시스템·네트워크 등 격리 |
| 커널 | VM마다 별도의 커널 | 같은 호스트의 컨테이너가 호스트 커널 공유 |
| 포함 대상 | 게스트 OS와 애플리케이션 | 애플리케이션과 실행에 필요한 사용자 공간 라이브러리·파일 |

컨테이너에서 Ubuntu 이미지를 사용해도 Ubuntu 커널을 새로 부팅하는 것은 아니다. 이미지의 사용자 공간 파일을 사용하고, 시스템 호출은 실행 환경의 커널이 처리한다.

## 질문 2

Task나 Pod를 하나의 VM이라고 봐도 될까?

## 답변 2

Task와 Pod는 컨테이너를 묶어 실행·관리하는 단위다. 내부적으로 어떤 격리 기술을 사용하는지와 사용자가 다루는 관리 단위는 구분해야 한다.

~~~text
서버 또는 실행 자원
└─ ECS Task / Kubernetes Pod
   └─ 하나 이상의 컨테이너
      └─ 실제 앱 프로세스
~~~

이미지는 실행에 필요한 파일과 설정을 담은 패키지이고, 컨테이너는 이미지를 기반으로 실행한 환경이다. Pod 안에 이미지만 올려 두는 것이 아니라 컨테이너가 실행된다.
